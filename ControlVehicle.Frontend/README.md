# ControlVehicle.Frontend

Frontend em React + TypeScript + MUI para consumo da API `ControlVehicle.Api`.

## Requisitos
- Node.js 20+
- NPM 10+

## Configuração
1. Copie `.env.example` para `.env`.
2. Ajuste `VITE_API_URL` se necessário.

## Execução
```powershell
npm install
npm run dev
```

Aplicação local: `http://localhost:5173`.

## Build
```powershell
npm run build
npm run preview
```
